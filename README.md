
<align='center'># Docker Learning

## Overview

This repository contains Docker basics, commonly used commands, Dockerfile examples, Docker Compose examples, and troubleshooting tips. It is intended for beginners and DevOps engineers who want to learn containerization.

## Topics Covered

- Docker Installation
- Docker Images
- Docker Containers
- Docker Volumes
- Docker Networks
- Dockerfile
- Docker Compose
- Docker Commands
- Docker Troubleshooting

## Prerequisites

- Docker Engine
- Docker Compose
- Linux or Windows with Docker Desktop

## Verify Installation

```bash
docker --version
docker compose version
```
